VAIDYA.OS  –  version 1.0
The digital operating system for Ayurvedic healthcare
(Offline health record for Ayurvedic OPD, with the CDAAT dosha & ama assessment built in)
=================================================

WHAT IS IN THIS FOLDER
  index.html, app.js, app.css, data.js   – the app
  manifest.webmanifest, sw.js, icons     – make it installable and work offline

PUT IT ONLINE FOR FREE (choose one, about 5 minutes)

  Option A – Netlify Drop (easiest)
   1. On a computer, open  https://app.netlify.com/drop
   2. Create a free account (or sign in with Google).
   3. Unzip this file and drag the whole "vaidya-os" folder onto the page.
   4. Netlify gives you a link like  https://something.netlify.app
      (you can rename it in Site settings → Change site name, e.g. vaidya-os-yourclinic).

  Option B – GitHub Pages
   1. Create a free GitHub account and a new public repository.
   2. Upload all files from this folder (not the folder itself).
   3. Settings → Pages → Branch: main → Save. Your link appears after a minute.

INSTALL ON THE PHONE
   Android (Chrome): open the link → menu ⋮ → "Install app" / "Add to Home screen".
   iPhone (Safari):  open the link → Share button → "Add to Home Screen".
   Open it once while online; after that it works without internet.

IMPORTANT – YOUR DATA
   • All patient data is stored only on that phone, inside the app.
   • Back up regularly: Settings → Back up now (use a password).
     Save the file to Google Drive or send it to yourself.
   • To move data to another phone or doctor: Settings → Restore / merge
     on the other phone with the same file. Records are merged, not duplicated.
   • Clearing the browser's data or uninstalling the browser deletes the records
     unless you have a backup.
   • Set a PIN in Settings to lock the app.

PRIVACY
   Take the patient's consent (tick box at registration). The app sends no data
   anywhere; nothing leaves the phone unless you share a PDF, a WhatsApp message
   or a backup file yourself.

UPDATING THE APP LATER
   Upload the new files to the same Netlify site / GitHub repository.
   Data on the phones is not affected.
